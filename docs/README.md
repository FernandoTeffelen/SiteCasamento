# Documentação interna

Esta pasta reúne documentos de operação e arquitetura. Ela é excluída do artefato da Vercel por [`.vercelignore`](../.vercelignore), portanto nenhum destes arquivos é servido pelo SiteCasamento.

- [DEPLOY.md](DEPLOY.md): publicação, atualização e restauração.
- [architecture/features.md](architecture/features.md): convenção de organização por funcionalidade.
- [operations/security-review.md](operations/security-review.md): revisão de segurança.
- [operations/production-test-report.md](operations/production-test-report.md): rodada de testes de produção.
- [operations/sentry.md](operations/sentry.md): monitoramento de erros.

`internal/` contém anotações, ideias, preços e o resumo do produto. É local e ignorado pelo Git para evitar a publicação acidental de material de planejamento.
